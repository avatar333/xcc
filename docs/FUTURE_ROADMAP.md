# Future roadmap

The current feature set ends at catalogue, Avenger planning, soldiers, equipment builds, and research planning. Future work may add:

- mission history, enemy encounters, Chosen tracking, resource inventory
- engineering and Proving Ground queues
- squad templates, soldier ability builds, resistance/faction tracking
- campaign calendar, Avatar Project tracking, bonds, fatigue/wounds, covert actions
- LWotC havens, infiltration/squad management, officers, force level, liberation chains
- mod import tools, Steam Workshop metadata, and a recommendation/advice engine

These are intentionally not implemented in the current phase.
