# Integrated dashboard and release check

The selected playthrough dashboard summarizes active packs, Avenger construction, facilities, soldiers and unavailable soldiers, builds, research progress/queue, missing prerequisites, and recent unlocks. Persistent navigation exposes Dashboard, Playthroughs, Avenger, Soldiers, Equipment Builds, Research, Catalogue, Content Packs, and Settings. Cards link to the relevant feature and empty states are intentional.

Release checks cover pytest, Ruff, empty-database startup, idempotent seed/import, ownership checks, upload safety, password hashing, and documentation. No future gameplay domain is implemented in this phase.
