# UI specification

The interface uses an original dark, futuristic visual language: cyan/blue accents, angular panel-like cards, readable typography, rich imagery when permitted, persistent left navigation, responsive layout, and modal/page forms. Navigation reserves space for Dashboard, Playthroughs, Avenger, Soldiers, Equipment Builds, Research, Catalogue, Mods/Content Packs, and Settings.

## Acceptance criteria

- Base layout and left navigation render for authenticated pages.
- Current campaign context is visible in campaign workflows.
- Catalogue cards display image/fallback, pack badge, type badge, and description.
